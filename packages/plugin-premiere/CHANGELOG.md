# @postpin-io/premiere-plugin

## 0.3.0

### Minor Changes

- **Faster uploads**: The render starts uploading right away while the plugin encodes the review versions on your computer, so the export is ready to review sooner.
- **Server version check**: If your PostPin server needs a different plugin version, the plugin says so and links to the right download.
- **Premiere Pro 26.2 or newer**: The plugin now needs Premiere Pro 26.2 or newer.
- **Icons**: The plugin has its own icons in Premiere.

## 0.2.0

### Minor Changes

- **First release**: The PostPin panel for Premiere Pro, as a .ccx file.
  - Render and upload a sequence, with a snapshot of its clips in their label colors.
  - Markers sync in both directions.
